# SM Debug Field Inspector

## 🚀 Features

- ✅ **Enhanced Debug Tooltip** - Shows field name, type, model on hover for ALL elements
- ✅ **Works on Monetary Fields** - Footer fields like amount_total, amount_tax, amount_untaxed
- ✅ **QWeb Content Support** - Works on computed and dynamically rendered content
- ✅ **Keyboard Shortcut** - Alt+F to toggle inspector on/off
- ✅ **Click to Copy** - Click any field to copy its technical name
- ✅ **Debug Mode Only** - Only activates when developer mode is enabled
- ✅ **Auto Hide** - Indicators automatically disappear when debug mode is disabled
